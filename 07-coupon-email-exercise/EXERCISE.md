# แบบฝึก: เลือกคูปองและส่งอีเมล (20 นาที)

ดัดแปลงแนวคิด coupon email จากบท 3–5 ของ Grokking Simplicity โดย Eric Normand มาใช้กับตะกร้าสินค้า ไม่ใช่การจำลองกติกาทั้งหมดของหนังสือ

เริ่มจาก `starter/coupons.go` ซึ่งเลือกคูปอง พิมพ์ log และส่งอีเมลในฟังก์ชันเดียว ใช้ `io.Writer` จำลองปลายทางอีเมล ไม่ต้องเชื่อมต่อบริการจริง

1. (3 นาที) จัดประเภท Actions / Calculations / Data ร่วมกับคู่ของคุณ
2. (10 นาที) แยก `FindApplicableCoupons(cart, coupons) []Coupon` ให้รับข้อมูลและคืนข้อมูลโดยไม่ log ไม่ส่งอีเมล และไม่เปลี่ยน input เขียน table-driven tests ก่อน implementation
3. (5 นาที) แยก `SendCouponEmail` ให้รับคูปองที่คำนวณเสร็จแล้วและส่งอีเมล ผู้เรียกต้องจัดลำดับสองขั้นตอนเอง
4. (2 นาที) เปรียบเทียบกับ `solution/` และอธิบายว่าทำไมฟังก์ชันที่คืนค่าอย่างเดียวอาจยังไม่ pure

กติกา: จำนวนเงินเป็นบาทเต็มและไม่ติดลบ ตะกร้ามีหมวดเดียว ใช้คูปองได้เมื่อยอดถึงขั้นต่ำและหมวดตรงกัน หมวดคูปองว่างหมายถึงทุกหมวด รักษาลำดับและคูปองซ้ำไว้ ไม่มีวันหมดอายุจึงไม่ต้องอ่านนาฬิกา

เทสต์ควรครอบคลุมรายการว่าง ต่ำกว่า/เท่ากับ/สูงกว่าขั้นต่ำ หมวดไม่ตรง ทุกหมวด ลำดับ และ input ไม่เปลี่ยน ส่วนการส่งอีเมลใน solution ตั้งใจเว้นเทสต์เพื่อเน้นขอบเขต side effect ที่บาง

```go
applicable := solution.FindApplicableCoupons(cart, coupons)
err := solution.SendCouponEmail(out, cart.Email, applicable)
```
