# แยกการคำนวณออกจากการกระทำ

`ApplyDiscount` รับ struct แบบ value แต่ slice ยังใช้ backing array เดียวกับผู้เรียก จึงเปลี่ยน input และให้ผลต่างเมื่อเรียกซ้ำ อีกทั้งพิมพ์ log ทุกครั้ง

`Discounted` รับยอดรวมแล้วคืนค่าใหม่ ทดสอบได้ด้วย input/output โดยไม่ต้องจำลองระบบภายนอก ส่วน `ProcessOrder` รวมการคำนวณเข้ากับการพิมพ์และบันทึกอย่างชัดเจน

ตัวอย่างใหม่กำหนดให้ปัดเศษครั้งเดียวที่ยอดรวม ซึ่งอาจต่างจากการปัดเศษทีละรายการในตัวอย่างเก่า เช่น `[501, 501]` ได้ 901 แทน 900 การ refactor งานจริงต้องตกลงกติกานี้ก่อน
